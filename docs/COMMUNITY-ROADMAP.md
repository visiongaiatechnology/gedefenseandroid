# Community Roadmap

The first public beta prioritizes evidence and compatibility over new sensor count.

Near-term work is organized around: Android/OEM compatibility reports, measurable battery/throughput behavior, Android 16/16 KiB runtime validation, clearer false-positive review UX, accessibility/localization review, public reproducible-build evidence, and issue-driven hardening of GaiaNet/XDR/scanner boundaries.

Features that increase privilege, remote control, payload inspection or destructive automation are not accepted merely because they look impressive. They require a separate threat model and explicit operator control.
