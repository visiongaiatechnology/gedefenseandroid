# Support

## Bugs and compatibility

Use a GitHub bug report for reproducible non-sensitive defects. Include GeDefense version, Android version, OEM/ROM, protection mode, whether TITAN/Device Owner is enabled, and sanitized reason codes.

## Security vulnerabilities

**Security contact:** [security@visiongaia.de](mailto:security@visiongaia.de)

Use GitHub private vulnerability reporting when enabled. Do not attach real packet contents, private keys, personal files, unredacted package inventories or identifiable diagnostics to a public issue.

## Diagnostics

The in-app Diagnostics & Support Center can export the aggregate-only support bundle through Android SAF. This is the preferred artifact for runtime troubleshooting because it intentionally excludes package identities, IPs, domains, file paths, signer/APK hashes and payload content.

## Scope

GeDefense Mobile is beta software. Community reports about OEM VPN behavior, Android 16, Always-on/Lockdown, Doze, network handover, 16 KiB page-size devices and unusual TCP/UDP behavior are particularly valuable.
